# ❤️ Heart Disease Risk Predictor

A machine learning web app that predicts heart disease risk from patient data.

## 🔗 Live Demo
[Click here to try the app] https://heart-disease-predictor-mlweb.streamlit.app/

## 📊 Model Performance
- Random Forest Accuracy: 98.54%
- XGBoost Accuracy: 98.54%
- Cross Validation Score: 99.71%

## 🛠️ Tech Stack
- Python, Scikit-learn, XGBoost
- SHAP (Model Explainability)
- Streamlit (Web App)
- Pandas, NumPy, Matplotlib

## 📁 Dataset
UCI Heart Disease Dataset — 1025 patients, 13 features
